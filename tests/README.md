# Проверки режима OSM

Запускать из корня решения:

```sh
dotnet run --project tests/SceneGenerator.OpenStreetMap.Checks
dotnet run --project tests/SceneGenerator.OpenStreetMap.DesktopChecks
```

Первый проект выполняет 50 автономных проверок без интернета. Второй открывает настоящее окно и проходит 24 проверки интерфейса; требуется доступная графическая сессия. Оба проекта используют готовую синтетическую сцену из `docs/examples` и удаляют свои временные файлы.

По флагу `--live` первый проект дополнительно обращается к публичному серверу Overpass. Это отдельная внешняя проверка и она может завершиться неудачей при недоступности сети или сервера. Другой сервер задаётся `--endpoint https://…/api/interpreter`. В ходе реализации живую загрузку подтвердить не удалось: ошибки TLS/504/тайм-аут. Основные автономные проверки от этого не зависят.

Сценарий окна успешно прошёл во время реализации. Позднее повторный запуск остановился с Avalonia.Native RenderTimer −6661 ещё до окна; такая же ошибка возникла у ранее работавшего оконного теста настроек. Причина не установлена. Это не результат функциональных утверждений теста; повторить при доступной графической сессии.

Тестовые проекты не добавлены в основное решение. Генератор и обычный запуск Desktop от них не зависят.


## 3D-отрисовка

`dotnet run --project tests/SceneGenerator.Rendering.Checks` проверяет проекцию, обратное преобразование, дворы, вогнутые контуры, видимость стен/крыш независимыми лучами, камеру, темы и неизменность JSON. Добавлена проверка масштаба ×1 по умолчанию и отсутствия растеризации на каждом событии движения во время вращения. Нужна доступная графическая сессия. Снимки пишутся в bin/.../artifacts.
