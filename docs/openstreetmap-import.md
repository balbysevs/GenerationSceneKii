# Режим «Территория OSM»

Добавлен 28 октября 2026 года. Это первый этап импорта реальной застройки: область пока задаётся координатами центра и размерами, без подложки карты и выбора рамкой мышью.

## Как пользоваться

1. Запустите `SceneGenerator.Desktop` и нажмите «Территория OSM» в шапке.
2. Укажите широту и долготу центра, длину участка по востоку и ширину по северу. По умолчанию задан центр Ярославля и участок 1000 × 1000 м. Центр области не назначает КИИ автоматически.
3. Нажмите «Загрузить из OSM». Можно также открыть сохранённый JSON-ответ Overpass с `out body geom` или проект импорта.
4. Выберите здание на плане либо в списке. Выбранное здание станет КИИ. Снимите флажки у зданий, которые нужно исключить. Исправляйте высоту выбранного здания в карточке; поле задаёт верхнюю отметку от местной земли, а не толщину поднятой части.
5. Прочитайте сводку качества. Оценочные высоты, пропуски и исключения показаны для проверки и не требуют дополнительной галочки перед использованием сцены. Оранжевые здания имеют оценочную высоту, выбранное здание выделено акцентом темы, исключённые — тёмно-серым.
6. При необходимости нажмите «Сохранить проект импорта…» **до** перехода в основное окно: так сохранятся исходные данные, географическая привязка, КИИ, правки высот и исключения. Существующий файл не заменяется; выберите новое имя.
7. Нажмите «Использовать сцену». Результат появится в прежнем списке сцен и общем 2D/3D-просмотрщике. Сохраняйте сцену прежними кнопками. Импорт успешно созданной сцены заменяет текущую серию, как генерация новой серии; отмена и ошибки сохраняют прежний результат.

Для проверки без интернета откройте `docs/examples/territory-demo.osm-project.json`. Это **синтетическая проверочная сцена**, а не реальный участок Ярославля. В ней есть двор, высоты из тегов и оценки, ручная правка высоты и исключённый объект. При открытии проекта координаты и размеры восстанавливаются из файла.

## Сервер и сохранённые данные

Адрес Overpass доступен в форме. По умолчанию используется опубликованный сервер VK Maps:
`https://maps.mail.ru/osm/tools/overpass/api/interpreter`.
Другие опубликованные адреса:
- `https://overpass-api.de/api/interpreter`
- `https://overpass.private.coffee/api/interpreter`

Перечень серверов и их условия: [OpenStreetMap Wiki](https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances).

Запрос выполняется одним POST с идентификатором приложения, тайм-аутом и отменой. Нет автоматического перебора серверов и бесконечных повторов. Частичный ответ с `remark` не принимается. Ответ ограничен 32 МиБ. Кэш хранится в LocalApplicationData/SceneGeneratorKii/OsmCache, действует семь дней и ограничивается при записи: до 16 собственных JSON-файлов и примерно 64 МиБ без учёта временной записи. Неисправность кэша не должна блокировать сетевую загрузку.

При проверке из текущей среды успешный сетевой импорт подтвердить **не удалось**: основной сервер дал ошибку TLS, VK Maps — HTTP 504, Private.coffee — тайм-аут. Проверены загрузка сохранённых ответов и сетевой протокол с подставным HTTP-обработчиком. Работоспособность конкретного публичного сервера зависит от сети и его состояния; онлайн-запрос нужно повторить при доступном сервере. Проверка сертификатов не отключалась.

В `docs/examples/yaroslavl-overpass.ql` находится готовый запрос для начального участка Ярославля. Его можно выполнить в Overpass Turbo и сохранить ответ как исходный OSM JSON, затем открыть его в приложении с соответствующими центром и размерами. Обычный экспорт GeoJSON, XML `.osm` и PBF этим загрузчиком пока не читаются.

## Архитектура

Новая библиотека `SceneGenerator.OpenStreetMap` зависит только от `SceneGenerator.Core` и стандартной библиотеки .NET. Новые внешние пакеты не добавлялись.

- `OsmImportOptions` — область, режим и параметры оценки высот; ограничения импорта отделены от случайной генерации.
- `IOsmDataProvider` — интерфейс получения данных. `OverpassDataProvider` загружает ответ, `FileOsmDataProvider` читает ответ или проект с диска.
- `OsmImportService` — асинхронная загрузка и запуск разбора вне UI-потока.
- `ICoordinateProjector` / `LocalCoordinateProjector` — географические координаты WGS84 → геоцентрические ECEF → местные East/North, со смещением к прямоугольнику сцены.
- `OsmBuildingParser` — здания `way` и `relation`/`multipolygon`, соединение фрагментов контуров, дворы, проверка геометрии, сообщения о пропусках.
- `BuildingHeightResolver` — высота, этажность и крыша, запасное значение; сохраняет происхождение высоты.
- `OsmImportDocument` и `OsmBuilding` — промежуточные данные и список замечаний до создания `Scene`.
- `OsmSceneSource : ISceneSource` — адаптер результата проверки к тому же интерфейсу, что реализует `GeneratedSceneSource`. Выдаёт одну импортированную сцену с КИИ первым.
- `OsmImportProject` — локальное сохранение исходного ответа, настроек, привязки и исправлений. Это другой документ, не формат обмена с решателем.

В Desktop добавлены отдельные окно, модель и контроль предпросмотра. Подключение к главной модели находится в `MainViewModel.Osm.cs`. В прежних файлах добавлены только ссылка на библиотеку, создание сервиса окна, кнопка и блокировка команды при занятости. Прежние конструкторы сохранены. Расчёты Core, случайный генератор, Console, DTO и экспортёр не менялись.

Используются адаптер источника, стратегия получения данных и внедрение зависимостей. Синхронный `ISceneSource` не выполняет сетевой запрос: загрузка и подготовка происходят до предоставления готовой сцены.

Пример использования из консольного кода:

```csharp
using SceneGenerator.Core.Contracts;
using SceneGenerator.OpenStreetMap;

var options = new OsmImportOptions { Latitude = 57.6261, Longitude = 39.8845 };
var document = await new OsmImportService(new FileOsmDataProvider("overpass.json"))
    .LoadAsync(options);
// Идентификатор КИИ выбирает пользователь из document.Buildings.
ISceneSource source = new OsmSceneSource(document, selectedBuildingId);
foreach (var scene in source.GetScenes())
{
    // Общий просмотр, обработка либо JsonSceneExporter с source.type = openstreetmap.
}
```

## Координаты и высоты

X направлен на восток, Y — на север, Z — вверх, единицы — метры. Географический центр участка отображается в `(length/2, width/2)`. Используется локальная касательная плоскость WGS84; вычисленный геоцентрический компонент Up не выдаётся за рельеф. Математическая основа: [PROJ, geocentric to topocentric](https://proj.org/en/stable/operations/conversions/topocentric.html).

Приоритет высоты: корректный `height`, затем `building:levels × высота этажа` с доступными параметрами крыши, затем пользовательское запасное значение. Этажность даёт оценку. Тег `height` также не гарантирует геодезическую точность. При `min_height` он задаёт нижнюю отметку, а верх по-прежнему берётся из полного `height`; высота призмы равна разности. [Модель Simple 3D Buildings](https://wiki.openstreetmap.org/wiki/Simple_3D_Buildings).

Параметры случайного генератора не применяются к реальным зданиям. Высота импортированной сцены определяется зданиями; значения не обрезаются до 40/50 м. В текущем импортёре верхняя отметка ограничена 1000 м. В 2D все высоты и основания передаваемой сцены равны нулю.

## Что поддерживается и что остаётся

- Размер области — 100–20000 м по каждой стороне; до 5000 принятых контуров, до 2000 вершин в одном контуре. Полярные области за ±80° и пересечение меридиана 180° не поддерживаются.
- Здания, выходящие за край участка, не обрезаются и не включаются: об этом есть сообщение. Смещайте или расширяйте область. Запрос Overpass с географическим bbox не является геодезической гарантией полноты всех объектов, пересекающих область.
- Дворы и составные кольца поддерживаются. Раздельные внешние контуры одного отношения представлены отдельными объектами; один из них можно выбрать КИИ. Составной КИИ из нескольких корпусов пока не реализован.
- Общие границы соседних зданий допускает существующая геометрия Core. При наложении площадей конфликтующая помеха автоматически исключается из создаваемой сцены. Выбранный КИИ имеет приоритет; среди остальных объектов сохраняется первый допустимый в порядке импорта. В основном окне показывается число исключений и первые идентификаторы; полный список причин доступен в `OsmSceneSource.SkippedBuildings`. Исходные данные OSM не удаляются.
- Крыши плоские, рельеф ровный. Полноценные `building:part`, сложные крыши, дороги, деревья и цифровая модель рельефа не моделируются. Карта с подложкой и выбор области рамкой — следующий этап интерфейса.

## Экспорт и атрибуция

JSON для второй команды использует прежний DTO: `source.type = "openstreetmap"`, без Seed и номера случайной генерации. Контуры, дворы и высоты сохраняет прежний экспортёр. Географическая привязка и происхождение исправлений сохраняются в отдельном проекте импорта; для интерпретации местных координат решателю они не требуются.

При распространении данных OSM сохраняйте сведения об источнике и лицензии. В окне и проекте импорта указаны `© OpenStreetMap contributors` и ODbL; сведения об источнике следует передавать вместе с производными данными. [Условия OpenStreetMap](https://www.openstreetmap.org/copyright).

## Проверки

Пройдено 50 автономных проверок OSM и 31 прежняя проверка генератора. Автономные проверки находятся в `tests/SceneGenerator.OpenStreetMap.Checks`: контуры, составной двор, соприкасающиеся и пересекающиеся здания, преобразование координат, происхождение высот, 2D/3D, ручные правки, сохранение/чтение проекта, прежний DTO, HTTP, кэш и отмена.

```sh
dotnet run --project tests/SceneGenerator.OpenStreetMap.Checks
```

Проверка настоящего оконного цикла — `tests/SceneGenerator.OpenStreetMap.DesktopChecks`. Открывает собственное окно, проверяет импорт, просмотр, обе темы, сохранение, отмену и возврат к генератору, затем закрывает его. Нужна рабочая графическая сессия; проверено на macOS. Снимки и результат сохраняются в `bin/.../artifacts` проверочного проекта. В ходе реализации пройдено 24 проверки настоящего окна. Поздние повторные запуски, включая прежний оконный тест настроек, остановились до создания окна с ошибкой Avalonia.Native RenderTimer −6661. Причина отказа графической подсистемы не установлена; повторную проверку нужно выполнить в доступной графической сессии macOS.

```sh
dotnet run --project tests/SceneGenerator.OpenStreetMap.DesktopChecks
```

Тестовые проекты не включены в основное решение и не нужны для обычного запуска приложения.

## Автоматическое исключение конфликтов

29 октября добавлено автоматическое исключение помех, которые не проходят добавление в сцену (пересекаются с КИИ/принятыми зданиями либо выходят за границы). После проверки оставшаяся сцена сразу передаётся в общий просмотр. Выбранный КИИ не исключается; его неверные параметры по-прежнему показываются как ошибка. Ручные ошибки высот также требуют исправления. Удаление относится только к составу создаваемой сцены, а не к данным на сервере OSM или исходному файлу.
