# Сверка проекта с техническим заданием

Дата обновления: 27 октября 2026 года.

Проверяется проект **«Генератор пространственных сцен для радаров»**. Задача второй команды — оптимизация размещения радаров — в объём этого проекта не входит.

## Результат

Генерация, работа с JSON-настройками, сохранение результатов и просмотр сцен в 2D/3D реализованы в соответствии с основными ограничениями ТЗ и согласованными изменениями. Оконный цикл на macOS и серии до 5000 сцен с 20 помехами проверены. Совместная проверка с решателем, дополнительные целевые устройства и подготовка к сдаче отложены.

## Проверка требований

| Требование | Состояние | Реализация и замечания |
| --- | --- | --- |
| Библиотека классов, доступная консоли и оконному приложению | Выполнено | Оба приложения используют `SceneGenerator.Core`; Core не зависит от Avalonia. JSON вынесен в `SceneGenerator.Serialization`. |
| Режимы 2D и 3D | Выполнено | В 2D отметки и высоты равны нулю. В 3D хранятся основание и высота призмы; отображаются стены и крыши с учётом перекрытия. Есть вращение, наклон, масштаб и переключение на вид сверху. |
| Сцена: длина/ширина 10 000–20 000 м, высота 3–50 м в 3D | Выполнено | Ограничения проверяет `GenerationSettingsValidator`; поля формы имеют соответствующие диапазоны. |
| КИИ: длина/ширина 50–4 000 м, высота 3–30 м в 3D | Выполнено | КИИ размещается в центре участка. Дополнительно проверяется, что высота КИИ помещается в сцену. |
| Расстояние от КИИ до ближайшей помехи 100–2 000 м | Выполнено | Считается между границами объектов в горизонтальной плоскости. Одна помеха создаётся на заданном расстоянии, остальные располагаются не ближе. При нулевом числе помех требование не применяется. |
| Количество и диапазоны размеров помех | Выполнено | Количество неотрицательное, отдельного максимума в ТЗ нет. Длина/ширина 20–100 м, высота 3–40 м в 3D; минимум диапазона не превышает максимум. |
| Расстояние между помехами 10–100 м | Выполнено в принятой трактовке | Настройка задаёт минимальный допустимый зазор между границами, а не максимальное расстояние для каждой пары объектов. Реальный зазор может быть больше. |
| Количество сцен 1–5 000 | Выполнено | Генератор выдаёт указанное число сцен с разными идентификаторами. В проверке лимита создано 5 000 сцен без помех; это не нагрузочный тест максимальной плотности застройки. |
| Объекты не пересекаются и находятся в границах участка | Выполнено | Проверяются горизонтальные пересечения, расстояния и нахождение объектов внутри объёма сцены. |
| Входной JSON настроек | Выполнено для консоли и окна | Общий `JsonGenerationSettingsReader` читает файл и вызывает валидатор. В окне кнопка «Загрузить настройки» заполняет форму. Ошибка загрузки сохраняет прежние параметры и сцены. |
| Сохранение параметров формы в JSON | Выполнено | Кнопка «Сохранить настройки» использует `IGenerationSettingsWriter` и `JsonGenerationSettingsWriter`. Полученный файл подходит консоли и окну. Замена существующего файла требует подтверждения; неверные параметры не записываются. |
| Выходной JSON, КИИ первым | Выполнено с согласованным расширением формата | В массиве `objects` первым идёт КИИ. Обычная генерация создаёт прямоугольники с четырьмя вершинами. Формат также поддерживает многоугольники и внутренние контуры. |
| Сохранение консолью в Result | Выполнено | По ранее принятому решению каждый запуск создаёт подпапку `Result/run-…`. |
| Просмотр и переключение сцен в оконном приложении | Выполнено | Сцена выбирается щелчком в списке. Есть вид сверху и объёмный 3D-вид, сетка, масштабирование, перемещение, приближение к КИИ и сведения при наведении. Отдельных кнопок «Предыдущая/Следующая» пока нет. |
| Сохранение результатов из оконного приложения | Выполнено | Сохранение одной выбранной сцены или всей текущей серии с выбором папки. При конфликте имён существующие файлы не заменяются. |
| Очистка результатов текущего сеанса | Выполнено | Удаление выбранной сцены и очистка списка требуют подтверждения. Сохранённые JSON-файлы не удаляются. |

## Согласованные изменения исходного ТЗ

- Используется современный .NET 10 вместо .NET Framework 4.7.2; оконный интерфейс — Avalonia для работы на macOS и Windows.
- Вместо ограничения формата четырьмя точками поддерживаются многоугольные контуры, в том числе с внутренними дворами. Прямоугольник остаётся частным случаем. Высота задаётся отдельно от горизонтального контура.
- Расстояния измеряются между границами объектов. КИИ находится около центра; текущая реализация выбирает точный центр.
- Вторая команда сама выбирает точки радаров. Передаются правила допустимого размещения на КИИ; поле `centerPoint` и выбранные координаты радаров отсутствуют.
- OpenStreetMap добавлен 28 октября как отдельный дополнительный режим: область задаётся центром и размерами, здания загружаются через Overpass или из файла. Импорт описан в [инструкции](openstreetmap-import.md). Выбор рамкой на карте и генерация рельефа пока отсутствуют; поверхность ровная. Диапазоны исходного ТЗ сохраняются для случайного генератора; реальная застройка проверяется отдельно.
- В объёмном просмотре используется ортографическая камера. Для наглядности доступен масштаб высоты ×1, ×10 и ×25; по умолчанию ×1. Это настройка изображения, она не меняет размеры объектов, настройки генерации или JSON для второй команды.

## Что осталось до завершения

1. Проверка обмена файлами с решателем второй команды — отложена до появления их проекта. Выходные файлы генератора уже проверены.
2. Подготовка сборок и инструкции распространения перед сдачей — отложена по решению команды. Оконный цикл и нагрузочные профили проверены 27 октября; дополнительные платформы и параметры потребуют своих проверок.

Замечание по устойчивости: Core сообщает об ошибке, если не удалось разместить помеху за заданное число попыток. Оконное приложение показывает такое сообщение и сохраняет прежний результат. Консоль перехватывает эту ошибку, показывает сообщение и число успешно сохранённых сцен, затем завершается с кодом 1 без трассировки стека. Обещать успешное размещение произвольного количества помех на ограниченной площади нельзя.

## Выполненные проверки

- Всё решение из четырёх проектов собирается без ошибок и предупреждений.
- Проверены нижние и верхние границы настроек, а также отклонение значений за их пределами.
- Для 48 сцен в режимах 2D/3D проверены количество и размеры объектов, порядок КИИ, положение в центре, нахождение внутри сцены, отсутствие пересечений и зазоры между границами.
- Проверена выдача 5 000 простых сцен с уникальными идентификаторами.
- Выполнен реальный цикл консоли: чтение JSON-настроек → генерация → JSON-файлы в Result.
- Проверены подтверждение и отмена удаления, выбор соседней сцены, блокировка несовместимых действий и сохранение исходных номеров/Seed после удаления.
- Проверено, что удаление из списка и очистка не меняют ранее сохранённые JSON-файлы.
- Проверены сохранение и чтение настроек 2D/3D, пустой Seed, отмена диалогов, подтверждение и отмена замены файла, повреждённый JSON и ошибки доступа.
- Проверено сохранение прежних параметров при неудачной загрузке, блокировка несовместимых действий и неизменность Seed/номеров уже созданных сцен после загрузки настроек.
- Проверены привязки новых кнопок и размещение шапки при минимальной ширине окна. Нативные диалоги выбора файлов подключены; их интерактивное прохождение пользователем в этой проверке не выполнялось.
- Консоль успешно создала сцены из файла, сохранённого командой оконного приложения. Для заведомо плотной застройки проверено понятное завершение при невозможности разместить помехи.

- Для 3D проверены преобразование координат и обратная проекция, внутренние дворы, вогнутые контуры, ненулевая отметка основания и приподнятые здания.
- Видимость стен и крыш сравнена с независимым расчётом пересечения луча с геометрией при разных углах камеры и масштабах высоты. Порядок объектов не влияет на выбор видимой поверхности.
- Проверены обработчики мыши: вращение, наклон, перенос правой кнопкой и Shift + левой, колёсико и освобождение захвата указателя.
- Приближение к КИИ проверено в том числе для узкого высокого здания при масштабе высоты ×25. Просмотр и вращение не меняют выходной JSON.
- Получены и просмотрены снимки обеих тем. 27 октября пройден автоматизированный цикл с настоящим окном на macOS. Windows и ручное прохождение стандартных системных диалогов выбора файлов не проверялись.

Проверочные сценарии запускались отдельно от основного решения; новые тестовые проекты в решение не добавлялись.


## Проверка 27 октября

Полный оконный цикл, серии по 5000 сцен в обоих режимах, повторная генерация, сохранение, очистка и расход памяти описаны в [отчёте проверки](acceptance-2026-10-27.md). Ускорен расчёт расстояний для прямоугольников; общий алгоритм для многоугольников и формат JSON сохранены.
