SceneGen 0.1.0 — генератор пространственных сцен

Сборка для 64-разрядной Windows на процессорах Intel или AMD.

1. Распакуйте архив целиком (команда «Извлечь всё»).
2. В распакованной папке SceneGen откройте SceneGen.exe.

Оставьте файлы и подпапки рядом с SceneGen.exe: они нужны для запуска.
.NET включён в сборку; Visual Studio и Rider не требуются.
Для загрузки территории из OpenStreetMap нужен интернет.

Сборка не подписана сертификатом издателя.
